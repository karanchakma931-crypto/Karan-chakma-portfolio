Karan Chakma - portfolio profile photo

FILES
  images/profile.jpg       600x600 square (use for the round avatar in the hero section)
  images/profile-full.jpg  full portrait (optional)

HOW TO USE
1. Upload the 'images' folder to the root of your GitHub repo (same level as index.html).
2. In index.html, replace the "KC" placeholder in the hero with:

   <img src="images/profile.jpg" alt="Karan Chakma" class="profile-img">

3. Add to your CSS:

   .profile-img { width:180px; height:180px; border-radius:50%; object-fit:cover; }

4. Commit and push; GitHub Pages updates in about a minute.
